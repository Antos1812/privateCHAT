
# WIADO - PL

Prosty czat działający po przez link z [render.com](https://dashboard.render.com) oraz database siedzącym na [Turso](https://turso.tech)

__Nazwa+Hasło__, posiada historię czatu, możliwość przesyłania zdjęć, oznaczenie się wzajemnie

## Dzięki Turso
Po resecie renderer lub po wylogowaniu się, historia czatu nie zostaje utracona, wszystko zostaje zapisane poprawnie.

## Jedna nazwa do jednego hasła
Każdy może zająć jedną nazwę pod jednym hasłem. Nie ma możliwości by kilka osób miało tą samą nazwę.


# WIADO - ENG

Chat is running on [render.com](https://dashboard.render.com) and on database from [Turso](https://turso.tech)

__Name+Password__, it have chat history, photos and mentions

## By Turso
whole chat history is safe, that means after renderer reset or your logout, history of the chat is safely stored without any problems.

## One Name to one password
There's no possibility to get couple people have same name with different passwords.
